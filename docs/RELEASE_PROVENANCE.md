# 发布来源与边界

本包的模型、训练、生成、数据加载和 checkpoint 辅助代码从作者保存的原始 PEGM 历史快照 `b1c22b7531ef72f7749b8476d8b10037a483aa86` 中恢复。保留的文件为 `models/` 下的 PEGM 核心组件、`utils/` 下的运行时辅助模块、`train.py` 与 `generation.py`。

`configs/paper_main.example.json` 基于同一快照的主实验配置整理：模型和损失超参数保持该快照的值，日志、数据、权重与恢复目录改为不含机器信息的占位路径。训练入口只做了两个运行安全修复：创建日志父目录，并在不存在恢复目录时从头训练而非报错。

以下内容被明确排除：未提交的后续工作区改动、EnzyPGM-2/EnzyMatch/EnzyPock-2 材料、OpenESM/fairseq 的第三方副本、Python 字节码、模型权重、原始数据、结构文件、缓存、日志和结果。仓库中的评估脚本是用于生成输出的轻量序列恢复率汇总工具，不应被解释为论文主结果的完整再计算。
